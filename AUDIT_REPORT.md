## Область проверки

Проверена надстройка, запускаемая через **`go run ./cmd/web`**, относительно исходного коммита `76b2ff96c1ded7eaa04df02fec4c457a0b09d0f5`.

Исходный `cmd/server/main.go`, его обработчики, прежний генератор и прежний интерфейс сохранены по условию владельца. Их известные ограничения не устранены внутри старых файлов. Доработанный HTTP-путь использует новые функции в тех же пакетах. README заполнен отдельно по запросу; остальные 22 исходных файла проверены побайтно.

## Проверка работающего сервера

Через настоящие loopback HTTP-запросы проверены главная страница, неизвестный маршрут, три AI API, оба примера генерации, запрещённый путь баннера, короткий и слишком длинный ввод.

Нагрузка: **240 генераций, 24 параллельных worker**, баннеры чередуются. Для каждого ответа проверены статус `200` и собственный текст запроса, чтобы выявить смешивание результатов. Все запросы прошли. На данной машине: суммарно около 0,039 s, p95 около 5,30 ms, максимум около 7,05 ms. Это короткая локальная проверка изоляции и устойчивости, не оценка производительности публичного хостинга.

Собранный бинарник дополнительно запущен из другой папки с абсолютным `APP_ROOT`, ответил `200` и завершился по SIGTERM с кодом `0` в пределах пяти секунд.

## Проверка в браузере

- Главная страница и три карточки баннеров отображаются.
- Ввод `WELCOME` даёт mock-подсказки; подбор по правилам выбирает Shadow с пояснением.
- Вариант `~ WELCOME ~` подставляет текст и Thinkertoy; генерация показывает рисунок.
- Короткий ввод скрывает подсказки; кириллица вызывает сообщение о поддерживаемом алфавите.
- Копирование подтверждено сравнением буфера обмена с текстом результата.
- Файл `symbol-thinkertoy.txt` действительно скачан; его содержимое точно совпало с результатом.
- После перезагрузки история сохранилась, выбранная запись повторно сгенерирована.
- При ширинах **1280, 390 и 320 px** нет горизонтального переполнения документа. При 320 px `scrollWidth == innerWidth == 320`; широкая надпись прокручивается внутри результата.
- Проверены подписи формы, отсутствие повторяющихся id, POST-метод и клавиатурно доступный блок результата.
- В отдельном процессе с `LLM_BASE_URL=http://127.0.0.1:1` подсказки/идеи показывают понятную ошибку; локальная рекомендация и генерация продолжают работать.
- В просмотренных журналах браузера не обнаружены ошибки JavaScript.

Сохранены снимки десктопного и мобильного интерфейса. Обычная HTML-форма проверена HTTP-тестами без зависимости от выполнения JS. Другие браузерные движки отдельно не запускались.

## Уточнения и пределы проверки

1. **Команда запуска существенна.** Старый `cmd/server` не объявляется исправленным. Аудит готовой версии должен использовать `cmd/web`, как указано в README.
2. Внешняя модель не была настроена пользователем. Проверены реальный HTTP-протокол с локальным тестовым backend, сетевые ошибки и таймаут; качество ответов конкретной модели и доступ к конкретному провайдеру ещё зависят от его настройки.
3. Публичное развёртывание, TLS, длительный нагрузочный прогон, полная матрица браузеров и формальная WCAG-сертификация не выполнялись.
4. Страница good-practices из задания прочитана: проверены разделение ответственности, обработка ошибок, организация файлов, документирование и форматирование добавленного кода. Общая рекомендация о пятиминутном времени исполнения не применяется как остановка постоянно работающего HTTP-сервера; отдельные запросы ограничены существенно меньшими таймаутами.
5. Абсолютная безотказность и прохождение любого неизвестного аудита не обещаются. Зафиксированы конкретные требования, тесты, результаты и ограничения.
